## 4. Process (as in the previous runs)

- Per item: spec → plan (small test-first tasks, exact files, gates, review focus, real-app check, empty
  Execution record) → build strictly test-first, one commit per task (see each test fail, then pass) →
  independent review on the strongest model (security focus for auth, tokens, files, sync, backup) → one fix
  wave (a second one when a security review finds more) → mutation check of at least three new tests →
  merge `--no-ff` into the collection branch → full gates on the merged tree → merge the collection branch
  `--no-ff` into `develop`, push, **wait for CI green** → comment on and close the issue → update
  `docs/ROADMAP.md`.
- Every non-obvious decision: `Ruling: <what> — <why> — <cost if wrong>` in the spec or plan.
- Licensing first (bundle nothing whose licence is unclear; credit on the Sources page), then best UX.
- Every rule a second client must follow: `docs/contracts/<area>/` README + JSON fixtures, decoded by Go and
  web tests; keep `overview.md` and the contracts README table current; keep `docs/wiki/` and the README
  accurate (doc tests check them).
- New routes: a `route{}` row with the right access value **and a deliberate personal-access-token rule**
  (5th field, default `noTok`; the pinned token route set is amended only with a Ruling), 401 + two-user
  isolation tests, the PWA route fixture (`UPDATE_ROUTES_FIXTURE=1`; default not cacheable), regenerate
  `docs/wiki/API-Routes.md` (`node scripts/gen-api-docs.mjs`). Escalating admin routes use
  `requireAdminReauth`.
- Commits: conventional, each message ends with a blank line and exactly
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` (owner's instruction; no model names in commits,
  code or docs). Never force-push or rewrite history.
- No browser automation; verify with unit tests, jsdom component tests (`*.dom.test.ts`) and built servers
  driven by curl/Python on a free 127.0.0.1 port (not 8080, 8085, 8300). Never touch the container named
  `qinqin` or `/home/user/qinqin-deploy` if they exist on the machine.
- At most three agents at a time on four cores; Go gates under a shared `flock`.
