## The rules (the contract's wording, short)

Citation tones are the dictionary's (CC-CEDICT, the server's readings). Spoken tones are worked out from them, per
reading, from the syllables, their characters (when the written form is one Han character per syllable) and the word
boundaries:

1. **不** (bù, citation 4) before a syllable whose citation tone is 4 is spoken **2**.
2. **一** (yī, citation 1) is spoken **2** before a 4th tone and **4** before a 1st, 2nd or 3rd tone; it stays **1**
   alone, at the end, before a neutral tone, after 第 or 初 (an ordinal), and next to another numeral
   (〇一二三四五六七八九十 and 两: a number read digit by digit, 十一, 一一).
3. **Third tones** (citation 3), right to left: a 3rd tone before another 3rd tone is spoken **2** — inside a word
   compared with the next syllable's citation tone (a run inside a word: all but the last), across a word boundary
   compared with the next syllable's spoken tone (我|很好 is 3-2-3, 展览|馆 is 2-2-3). Without boundaries the reading
   is one word.

Not covered (documented): 一 and 不 as neutral tones inside reduplications and A-not-A questions (看一看, 是不是:
CC-CEDICT gives citation tones there, still accepted), third tone before a neutral tone that was a 3rd (小姐), and
the half-third tone (a contour, not a tone number).

## Rulings

- Ruling: the settings key is `tones: {showSandhi: boolean, gradeSpoken: boolean}`, defaults `true` and `false`,
  each member alone (anything but a boolean is the default), written one member at a time by merge patch — the
  same shape as `visualAids`, a key per area so #180 can add drill settings beside them — cost if wrong: a
  renamed key before anyone stores it.
- Ruling: a card entry is **one word** for the third-tone rule; the tone card does not call the segmenter — the
  segmenter is a greedy longest match over the dictionary (`internal/segment`), so it returns a dictionary entry
  whole; asking it would be a round trip that changes nothing. The rule takes word boundaries (`words`, syllable
  counts) for running text (a sentence, the drill's sentences, the reader later), and the fixtures pin them — cost
  if wrong: an entry that is itself a phrase (我很好) gets the one-word form (2-2-3); with the default grading
  both 3-2-3's 我 (citation) and 2 (spoken) are accepted anyway.
- Ruling: 不 and 一 are recognised by **character and syllable** (the character 不 with the syllable bu, 一 with
  yi), so only a written form of one Han character per syllable (`tonePadLabels`) gets those rules; erhua forms and
  mixed scripts get the third-tone rule only — the pinyin alone cannot tell 一 from 衣 — cost if wrong: such a card
  grades citation tones on 不/一, as before.
- Ruling: 一 rules use the next syllable's **citation** tone (一起 yì qǐ, 一百 yì bǎi), and 不/一 are applied before
  the third-tone rule (which only looks at citation 3rd tones, so they do not interact) — the standard textbook
  order — cost if wrong: none found in the fixture.
- Ruling: 一 stays 1 after 第/初 and next to numerals, but 一 before 百/千/万/亿 follows the normal rule (yì bǎi,
  yì qiān, yí wàn) — the counting form — and dates (一月) are not special-cased: 月 is a 4th tone, so 一月 grades yī
  (citation) and yí (spoken) by default — cost if wrong: with "Grade spoken tones" on, 一月 asks yí; rare as a card.
- Ruling: by default each syllable accepts its citation tone **or** its spoken tone, independently (a learner
  who gives the spoken tone on 不 and the citation tone elsewhere is right) — the owner: "a spoken tone on a sandhi
  syllable is also accepted, since it isn't a mistake" — cost if wrong: none; it only widens per syllable.
- Ruling: with "Show tone sandhi" off the answer shows only citation tones **also** when "Grade spoken tones" is
  on — the owner's "when off, sandhi is never shown"; the card then says above the pads that spoken tones are
  graded, so a learner is not left guessing — cost if wrong: a learner with that combination sees `bù` marked
  against a 2; the settings note says so.
- Ruling: the card says "Mark the tones as spoken (tone sandhi)." under the prompt when spoken tones are graded, and
  nothing in the default mode (#180: "say which the exercise grades"; by default the familiar dictionary tones are
  graded) — cost if wrong: one line.
- Ruling: the answer shows the spoken tone only on syllables where it differs (`bù → bú`, `kè`, `qi`), with an
  accessible name "fourth tone, falling, spoken second tone, rising"; with pinyin hidden `4ˋ → 2ˊ` and both
  contours — cost if wrong: cosmetic.
- Ruling: the full pinyin readings in the answer's reading table stay citation pinyin (the dictionary's) — the per
  syllable answer above already shows the spoken form — cost if wrong: one line more.
- Ruling: Settings > Study > **Tones** shows only for a workspace whose language profile has tones (Chinese) — Spanish
  has no tone cards — cost if wrong: none.
- Ruling: the Go side decodes `sandhi.json` in `internal/pinyin` (the numbered → marked reading the server sends and
  the citation tones) and `settings/tones.json` in `internal/lang` (the languages with the switch are the profiles
  with tones); the server does not apply sandhi (it grades nothing) — cost if wrong: a Go port of the rules later,
  against the same fixture.

## The "1-1-5" report

The owner remembers the card showing "1-1-5" for 不客气. Checked: the server sends `bù kè qi` (Go `ToMarked` of
`bu4 ke4 qi5`, pinned in `sandhi.json`); `parsePinyin` reads it as 4-4-5 (the grave accent is tone 4); the answer
row prints `verdict.best[i].text` of the reading, never the marked tones, and `data-answer-tone` is the citation
tone. Tests now pin it: `tones.test.ts` ("the answer it reports is the citation reading…": 1-1-5 marked gives
`bù kè qi`, tones 4-4-5, spoken 2-4-5) and `ToneCard.dom.test.ts` ("the 1-1-5 report": the rows show `bù → bú`,
`kè`, `qi`, tones 4-4-5, the first two marked wrong). **No rendering or matching bug found.** What the card does
show as 1-1-5 is the learner's own pads: a swipe within 25° of horizontal is a flat 1st tone (`toneFromGesture`,
`FLAT_DEGREES`), so a shallow rising swipe (bú) or a shallow falling one (kè) reads as tone 1 on the pad. That is
the likely source of the memory; the pads are the learner's input, so it is not changed here. Ruling: the gesture
thresholds stay — cost if wrong: the owner asks for a steeper flat band in a follow-up (one number), with the
phone check below.
