## Global constraints

- Package ids: `lexicon.<lang>`, `<type>.<packId>` for `levels|sentences|frequency|components|audio|grammar|strokes`.
  Package `formatVersion` 1 for every type. File `<data>/packages/<id>/r<revision>.qqpkg`.
- Pull v2 collections, round order (exact): `workspaces, pluginStates, pluginData, cards, decks,
  deckSettings, limits, fsrsSets, fsrsActive, books, bookmarks, highlights, overlays, sentences, events`.
  Moved names (400 `sync_collection_moved` in both forms): `entries, links, senses, levelMembers,
  dictionaries, schemes, levels`.
- `limit` 1..2000 (default 500); page byte budget 4 MiB of encoded rows (at least one row); token prefixes
  `p2.` (page) and `c2.` (cursor); cursor = `until − 30 s`.
- Errors are JSON `{error, message}` with codes added to `docs/contracts/auth/errors.json`:
  `sync_collection_moved` 400, `sync_page_invalid` 400, `sync_cursor_expired` 410, `package_not_found` 404,
  `package_revision_gone` 410 (`rate_limited` 429 exists). Legacy-form errors that were plain text stay
  plain text except `sync_collection_moved`.
- Every user-data query filters by `user_id` of the session; no package ever holds user rows.
- Fixtures: `{"version": 1, "rule": "<name>", "cases": [...]}`; changed only after re-deriving.

## Review focus (strongest model; must-fix findings block)

1. **Memory bounds.** v2 holds at most one page (rows ≤ limit, bytes ≤ 4 MiB + one row); the legacy form
   streams (one row in memory); package builds stream in 1,000-row batches; downloads use
   `http.ServeContent` on a file. No `[]Entry` of a whole table anywhere (grep `pullEntries` gone).
2. **Isolation.** Two-user tests for every v2 collection, the legacy form, the catalogue (no user data in
   it; `error` only for admins) and downloads; a page token or cursor of user A used by B is 400 and leaks
   nothing; `workspace=` of a foreign workspace is 404.
3. **Paging correctness.** No row lost or reordered under concurrent writes within a round; the 30 s lag;
   tombstones only with `since`; filter binding; language restart; library deletions; no `lookup` events.
4. **Packages.** Deterministic `contentHash`; revision +1 only on change, never reused; file SHA-256 equals
   catalogue; retention 7 days; failed build keeps the old revision; licences and attribution inside every
   package; no package of an unclear-licence pack beyond what the server already serves (packages contain
   exactly what is installed).
5. **Files.** Package and stroke paths built only from validated ids and integers (never a request string);
   `.tmp` + rename; Range/If-Range correct; no directory traversal through `{id}` or `{file}`.
6. **Compatibility.** Old shell (legacy form + strokes URL), item 4 legacy view, token scripts, PWA offline.

type PageRequest struct { V2 bool; Since string; Page string; Limit int; Only map[string]bool; Workspace int64 }
type Page struct {
  Format int `json:"format"`; InstanceID string `json:"instanceId"`; Until time.Time `json:"until"`
  Scope *Scope `json:"scope"`; Restarted []string `json:"restarted"`

type Scope struct { Workspaces []WorkspaceRef `json:"workspaces"`; Languages []string `json:"languages"`; Catalogue string `json:"catalogue"` }
