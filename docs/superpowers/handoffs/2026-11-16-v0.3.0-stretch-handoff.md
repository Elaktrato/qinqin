## 3. Rulings worth knowing (full text in each spec/plan)

- **#67:** one goal per workspace (`goals:workspace` row); target changes apply from today; vacation days
  are neutral for the goal streak; activity-based goals need the server, new-card and study-time goals
  work offline; the widget is home-only.
- **#75 licence:** no new frequency data bundled. Only Jiten (ja, CC BY-SA 4.0) is bundled; no clearly
  licensed Chinese word-frequency list exists (wordfreq/jieba/SUBTLEX-CH unclear; Leiden Weibo, BCCWJ
  incompatible) → Chinese workspaces see a hint until an operator installs a pack locally. Known word =
  vocab card score ≥ 80 (or a manual mark since #68). Starter deck ids `d-frq-<slug>-<fnv1a32>`.
- **#77:** notes are `qinqin-core` plugin rows `note:<entryId>` (not the overlay, which a save replaces
  whole); plain text only, never HTML; restore re-keys notes to the target's entry ids and drops invalid
  or unresolvable note rows.
- **#71 licence:** radicals from data already bundled (Unihan, KANJIDIC2); a Japanese component index
  derived from KanjiVG (CC BY-SA 3.0, pinned commit, licence text checksum-pinned) is bundled; Chinese
  decomposition (CHISE/cjkvi-ids GPL, Make Me a Hanzi LGPL) is local-only; KRADFILE not bundled (licence
  page unreachable from here).
- **#68:** one "known" rule shared with smart hiding: the reader uses the learner's smart threshold,
  everything else 80; manual marks (`known:<entryId>`) win everywhere; level lists never make a word known.
- **#83 (security):** `qq_pat_` + 64 hex, SHA-256 at rest, shown once; read/write scope, optional
  workspace limit, 1–365 day expiry; **fail-closed** per-route token rule (56 routes in v1, pinned by a
  test); never on auth, account, admin, backup/export/restore, tickets, AI, journal or workspace
  management; **no admin scope**; every containment action revokes tokens; rate limited per user;
  audited without token material. Independent security review: no blocking finding, 20 mutants all killed.
- **#81:** in-app only; Monday–Sunday in the learner's days; vacation days marked and neutral; an empty
  today is not counted against you; **milestones deferred** (need stored seen-state; not in the owner's
  direction) — consider a follow-up issue.
- **#72 (privacy):** one `qinqin-core` row `lookups` per workspace (≤ 500 words); Clear overwrites the row
  (no tombstone keeps the words) and deletes old `lookup` events through `DELETE /api/events/lookups`
  (the only exception to append-only events; nothing derives from them); the web app no longer posts
  `lookup` events; the service worker scrubs lookup rows/events from saved copies; a per-user recording
  switch. Known gap: a Clear racing another device's flush is repaired after 30 s, losing up to 30 s of
  that device's new lookups.
