# #346 — everyday meanings first; a pinned reading limits a card (2026-11-28)

Issue: "entries: one-character Chinese words list surname, abbreviation and variant lines first". Builds on #345's
sense display rule (`docs/contracts/senses/`); branch `feature/v090-346-sense-order` from
`feature/v090-345-sense-display`.

## What

1. **Minor lines last.** A third class between everyday and sensitive: a CC-CEDICT line whose first gloss is a
   surname, abbreviation, short name, variant, cross-reference ("see", "used in", "also written") or an archaic,
   old or classical note, and a JMdict sense tagged `arch`, `obs`, `rare`, `dated` or `surname`, is `minor`: shown
   after every everyday unit, never folded. 书 shows "book" before "abbr. for 書經", 水 "water" before "surname
   Shui", 三, 马, 云 (cloud before "(classical) to say"), and about 400 HSK words like them.
2. **A pinned reading limits the card.** Each CC-CEDICT sense carries its line's reading as a sense tag
   `reading:<pinyin>` (import), each JMdict sense its `<stagr>` restrictions the same way. The rule takes an
   optional pinned reading: only senses of that reading (and senses with no reading tag, which apply to every
   reading) are shown. The Starter set's pinned readings (猫 māo, 喝 hē, 蛇 shé, 头 tóu, 脚 jiǎo, 六 liù, 水 shuǐ,
   书 shū) travel with the card (`extra.reading`, set when the Starter words are added) and limit its back.
3. **"Usually kana" in the lookup** follows the first sense like the display form (目 and 山 are not usually kana:
   only a side sense is), so the popup no longer calls them "usually kana".

## Rulings

- Ruling: a CEDICT line is minor by its **first** gloss, as a whole — its later glosses ("Shui ethnic group",
  "abbr. for Malaysia") belong to the proper-noun line; a minor-looking gloss inside an everyday line stays (喝's
  "variant of 嗬" after "to drink") — cost if wrong: a few everyday glosses of a proper-noun line sit lower.
- Ruling: capitalised pinyin alone does not make a line minor — 汉 Hàn "Han ethnic group; Chinese" is the main
  meaning of a proper-noun line; only the surname/abbreviation/variant markers do — cost if wrong: a capitalised
  line without a marker stays in file order.
- Ruling: JMdict `abbr` is **not** minor (電話's "telephone (device)", 4,685 senses, many everyday); `arch`, `obs`,
  `rare`, `dated`, `surname` are. JMdict's own sense order is otherwise kept: its editors order senses by
  importance, and no tag says that 肉's "meat" (sense 2) or シャツ's outer shirt (sense 2) is the everyday one, so
  those keep JMdict's order (both meanings show on the card) — cost if wrong: 肉 leads with "flesh"; fixing it needs
  a reviewed per-word lead sense (a content follow-up, recorded below), not a rule.
- Ruling: minor units are never folded, only placed after the everyday ones ("last or folded": last keeps 书's
  classical meaning reachable without a tap) — cost if wrong: a longer card back for a few characters.
- Ruling: the sense's reading is stored as a sense **tag** `reading:<value>` (the line's marked pinyin as stored, or
  a `<stagr>` kana), not a new column — tags already travel in every answer, the data package and the pull, so no
  migration and no package schema change; a client that does not know the tag shows it nowhere (the popup filters
  it out of its chips) — cost if wrong: a later "readings per sense" column replaces the tag.
- Ruling: a pin compares ignoring case, white space and apostrophes (`shuǐ` matches CC-CEDICT's `Shuǐ` surname line,
  which the minor class then puts last; `huángsè` matches `huáng sè`), tone marks count (hē is not hè); a pin no
  sense has is ignored, so a card never goes blank — cost if wrong: a pin to the lowercase reading keeps its
  capitalised proper-noun line (last).
- Ruling: the pinned reading lives in the card row's `extra` (member `reading`, a string), not as a typed member — a
  typed member is a study-rows contract change with a column, backups and the merge rule; `extra` already carries
  members a client adds and every server stores and returns it verbatim; only the Starter add flow writes it —
  cost if wrong: another client that rewrites `extra` without the member drops the pin (the card then shows every
  reading's lines, as before).
- Ruling: the pin limits the **meanings** only; the readings on the front and back stay as they are (a Chinese
  entry's bopomofo cannot be matched to its pinyin line, and the Starter front already shows one reading) — cost if
  wrong: 猫's back still lists máo among its readings.
- Ruling: existing installations get the `reading:` tags only after `qinqin seed` re-imports CC-CEDICT and JMdict;
  until then no sense has a reading tag and a pin shows every line, exactly as before (the release notes say so).
- Ruling: the lookup's entry tag "usually kana" follows the first sense, like the display form; the ranking keeps
  the entry's `uk` flag (any sense), which decides how kana text matches (山's ヤマ jargon is written in kana) —
  cost if wrong: none for display; ranking unchanged.
- Ruling: 草 is not added back to the Starter set here — the set is reviewed content (#275) and adding a word needs
  its picture check and a teacher review; the adjudicators' condition (the cào line hidden) now holds, recorded as a
  follow-up.
