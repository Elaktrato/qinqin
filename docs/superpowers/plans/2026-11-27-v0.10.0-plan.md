# v0.10.0 plan — daily use, your own material, and the server around it (2026-11-27)

The owner's plan for milestone **"v0.10.0"** (GitHub milestone 9, 33 open issues on 2026-11-27). This milestone was
the v1.0.0 milestone until the owner renamed it: **v1.0.0 comes once the owner is satisfied, not at a fixed
point.** Every open question was answered in planning; the answers are below and as an "Owner decisions
(2026-11-27, v0.10.0 planning)" comment on each issue concerned. **An agent can work through this milestone without
stopping for the owner.** If something new comes up that this plan and the issues don't settle, make the call that
best fits the decisions here, write it down as a ruling in the issue's plan, and carry on.

**Starts after v0.9.0** is merged into `develop` (its plan: `docs/superpowers/plans/2026-11-26-v0.9.0-plan.md`).
v0.10.0 builds on v0.9.0's drills framework, the shared study core (#278), grammar events (#277), the German and
Japanese interfaces, and hidden romanisation (#284).

## 1. How the work runs

The same as v0.9.0 (§1, §2 and §6 of its plan):

- **Integration branch `feature/v0.10.0`** from `develop` after the v0.9.0 merge. One branch and one plan per issue,
  tests first for logic, `--no-ff` merges once CI is green on the merged state. A PR `feature/v0.10.0` → `develop`
  runs CI on the whole state; merging, tagging and releasing are the owner's call. Alpha tags are fine.
- **Contracts** with fixtures, a ContractVersion bump and a CHANGELOG entry for every shared rule.
- **Content review by native-language teacher subagents** (several, higher reasoning where possible), never waiting
  for the owner.
- **New text is translated as it lands:** every new interface string gets its `de` and `ja` translation in the same
  PR, reviewed by teacher subagents, so the German and Japanese interfaces from v0.9.0 stay complete.
- **Cloud environment and the local follow-up:** no Android SDK, emulator, Docker daemon or open network. Never fake
  a step; put what needs the owner's machine on the local follow-up list in the handoff.
- **Independent review** of the whole branch by the strongest available model, a fix wave, then
  `docs/superpowers/handoffs/<date>-v0100.md` and draft release notes in `docs/releases/v0.10.0.md`.
- **Phone first** (360 px, no horizontal scroll) and **hidden romanisation respected** on every new screen.
