# qinqin v0.2.0

First release since v0.1.0. It carries the v0.2.0 (study experience) and v0.3.0 (journal and AI)
milestones together. Image: `ghcr.io/elaktrato/qinqin:v0.2.0` (also `latest`). Deploying with
Portainer: see "Deploying with Portainer" in the README and `deploy/portainer-stack.yml`.

## Upgrading from v0.1.0

**Install fresh; do not upgrade a v0.1.0 database in place.** Migration 017 rebuilt the
dictionary tables with new entry ids and moves no data. A v0.1.0 database starts and migrates
without errors (012–031 apply, users, workspaces, settings and study events survive), but the
dictionary is emptied, and your own edits, sentences and flashcards then point at the wrong
entries after you re-seed. Start with a new data volume and run `qinqin seed`. Rehearsed on
2026-11-15 against a seeded v0.1.0 database.

For a fresh install:
- `QINQIN_SECRET` is required by the Portainer stack (needed for the AI features). Back it up
  separately from the data volume; without it stored API keys cannot be read.
- The published image is larger: Tesseract OCR adds about 193 MB and the Kanji alive audio
  about 70 MB.
- Later upgrades (from v0.2.0 on) migrate automatically; back up the volume first, there is no
  downgrade.

## What's new

**Study**
- Writing and tone cards: own stroke matcher that forgives real hands (joined strokes, hooks),
  snapping animation; tone swipes draw the tone's shape and pads show characters.
- Delete cards (undoable) and move them between decks; Again cards come back in the same session;
  FSRS optimizer with a Scheduling page (parameters are only applied when they fit your recent
  reviews better).
- Grammar lessons with fill-the-gap and word-order practice (demo pack).
- Search filters (kind, scheme, level) with shareable URLs.

**Journal and AI**
- Journal with AI review (underlined corrections, overall review), topic ideas, and photo import
  with offline OCR (Tesseract) or AI transcription.
- Choose your AI provider: Anthropic, OpenAI/ChatGPT, Google Gemini, DeepSeek, Mistral, xAI, Groq,
  OpenRouter, Ollama, or an admin-registered OpenAI-compatible endpoint. Your key is stored
  encrypted with `QINQIN_SECRET` and is never sent to the browser.

**Data and admin**
- Settings → Data (admin): upload packs with licence review, list and uninstall; Languages
  management; per-workspace hidden dictionaries.
- New level packs: Jōyō kanji grades and 通用规范汉字表 levels. Audio pronunciation (Japanese
  recordings from Kanji alive, CC BY 4.0; device voice elsewhere).
- Plugin SDK with permissions, and a core activity heatmap with per-type filters and an
  all-workspaces view. Stats moved to the footer.

**Engineering**
- Backend hardening (first-user race, login timing, plugin data, sync, import pipeline), web
  accessibility and auth fixes, component tests, CI hardening and a real-embed smoke test.

## Known limits

- The Journal and every AI provider were tested only against fake servers: some model ids and
  Gemini request fields are marked UNVERIFIED in `server/internal/ai/registry.go`. Test with your
  own key (checklist: `docs/superpowers/handoffs/2026-11-15-ai-providers-handoff.md`).
- Lumo (Proton) has no public API; it can only be used as a custom endpoint once one exists.
- The 40 grammar demo sentences have not been read by a native speaker.
- Heatmap days are UTC (#84); login has no rate limiting yet (#86).
- No automated backup yet (#61): stop the container and copy the volume.
- The Android app is not part of this release.

Full details per feature: `docs/superpowers/specs/`, `docs/superpowers/plans/`, and the handoff
`docs/superpowers/handoffs/2026-11-15-web-build-handoff.md`.
