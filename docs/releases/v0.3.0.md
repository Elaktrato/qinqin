# qinqin v0.3.0

Accounts, backup, offline study and the shared-data rules for the coming Android client, plus the
v0.3.0 stretch features. Image: `ghcr.io/elaktrato/qinqin:v0.3.0` (also `latest`).

## Upgrading from v0.2.0

- Back up the data volume first (there is no downgrade). Migrations **032–037** run on the first start:
  accounts (hashed sessions, audit, invites, resets), registration and users, SMTP and two-factor
  sign-in, per-user time zones, component packs, personal access tokens.
- Existing instances keep their effective registration policy (closed = admin creates users).
- Keep `QINQIN_SECRET`: the SMTP password, authenticator secrets and AI keys are sealed with it; a
  server backup can only be restored with the same secret.
- A reverse proxy must pass `Authorization`, must not cache `/service-worker.js` or the manifest, and
  needs a body limit of at least 130 MB for a personal restore upload.
- Without a reverse proxy set `QINQIN_TRUSTED_PROXIES=none` (sign-in rate limiting keys on the client
  address).
- v0.1.0 databases still cannot be upgraded in place (see the v0.2.0 notes).

## What's new

**Accounts and security**
- Registration closed by default, invite links, optional open registration, admin-created users with a
  forced password change, password-reset links, email policy (off / optional / required).
- Optional SMTP (admin only, password sealed): reset by mail, email verification, sign-in by emailed
  code. Two-factor sign-in with an authenticator app (TOTP) and recovery codes; the admin can require it.
- Sessions list, sign out others / everywhere, change password, delete your account; admin user
  management (disable, delete, promote; the last admin is protected).
- Sign-in rate limiting and lockout.
- **Personal access tokens** for scripts (Settings → Account): read or write, optionally one
  workspace, 1–365 days, shown once and stored hashed; refused on account, admin, backup and auth
  routes; revoked by every password change and sign-out-everywhere. See the wiki page
  `API-Access-tokens.md`.

**Study**
- Reverse and cloze cards (opt-in per deck), sibling burying until the next day.
- Flashcards decks view with deck stats, deck settings and system level decks you can add.
- Vacation mode (nothing due, no backlog afterwards, streak paused) and daily limits per workspace and
  deck. Level sessions for character schemes (JLPT kanji, Jōyō grades, 通用规范汉字表).
- **Daily goals** with a progress ring and a goal streak.
- **New-card order** by frequency or level, and **starter decks** (Top 500/1000/2000) from the
  installed frequency pack (Japanese: Jiten; no clearly licensed Chinese list is bundled).
- **Weekly summary** (Stats → Week and a home card), Monday–Sunday in your local days.
- Your day, heatmap and streaks now follow your own time zone.

**Reading and lookup**
- Reader display settings: ruby on/off and size, fonts, readings always / never / smart (hide the
  readings of words you have mastered).
- **Unknown-word highlighting** and text coverage per chapter and book, with "I know this" marks and
  bulk add to a deck.
- **Personal notes** on any entry, shown after the answer in study.
- **Lookup history** (`/lookups`) with add to deck, remove and clear; a recording switch.
- **Radical and component lookup** (`/search/parts`); Japanese components from KanjiVG (CC BY-SA 3.0).

**Your data and the app**
- Personal backup: export a zip and restore it (dry-run report, typed confirmation); admin server
  backup (`qinqin backup` CLI too).
- Installable app with offline study: due cards cached, reviews queued offline and sent once.
- `docs/contracts/` for the Android client and the user/admin/API docs as the wiki source
  (`docs/wiki/`).

## Known limits

- Nothing in this release was checked in a real browser, on a phone, against a real mail server or a
  real authenticator app before tagging: the hand-check lists are in
  `docs/superpowers/handoffs/2026-11-15-v0.3.0-handoff.md` (§2) and
  `docs/superpowers/handoffs/2026-11-16-v0.3.0-stretch-handoff.md` (§2).
- The Docker image of this release was not built locally before tagging (CI builds it).
- Chinese has no bundled word-frequency list or component data (licences unclear); the local-only
  scripts are documented.
- の shows as 乃 in Japanese starter decks; weekly milestones are not built yet.
- The AI features were still only tested against fake providers.
- The Android app is not part of this release.

Full details per feature: `docs/superpowers/specs/`, `docs/superpowers/plans/` and the two handoffs above.
