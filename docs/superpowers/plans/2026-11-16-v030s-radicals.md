# Radical and Component Lookup (issue #71) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development (fresh implementer
> per task or per few tasks, independent review on the strongest model, one fix wave). Strictly test-first:
> write the test, run it, SEE IT FAIL, implement, see it pass. Steps use checkbox (`- [ ]`) syntax.

**Goal:** `/search/parts`, a Kangxi radical table, a component picker and a stroke filter that narrow a
character grid. The data is the existing radical links (Unihan `kRSUnicode`, KANJIDIC2) plus a new
`components` pack type. One KanjiVG-derived ja pack is bundled under CC BY-SA 3.0. zh components are
local-only. The entry page links to "all characters with this radical".

**Spec (binding, incl. Rulings and the licence table):** `docs/superpowers/specs/2026-11-16-v030s-radicals-design.md`.

**Branch / worktree:** `feature/v030s-radicals` at `/home/user/qinqin/.claude/worktrees/radicals` (`<wt>`),
from `feature/v0.3.0-stretch`. Never merge or push: the orchestrator does that.

**Architecture:** Go: `internal/radicals` (the table), `lexicon.Characters` gains `Radical`, `/api/characters`
gains `k` (format 3), `internal/components` (import, list, index), `packs.go` dispatch, two public routes.
Web: `lib/radicals/kangxi.ts` (the table from the contract JSON), `lib/radicals/lookup.ts` (pure filter and
narrowing), `lib/radicals/url.ts` (selection ↔ URL), `lib/api/components.ts` (shared-request cache like
`lib/api/characters.ts`), a thin `routes/search/parts/+page.svelte`, and links from search and the entry page.
Scripts: `prepare-kanjivg-components.mjs` and `fetch-kanjivg-components.sh` (bundled ja pack), and
`prepare-ids-components.mjs` (local-only zh).

**Tech stack:** Go 1.26 (GOTOOLCHAIN=auto), SQLite migrations, SvelteKit 2 / Svelte 5, vitest (unit and
jsdom), Node scripts with `node --test`. No new dependencies. The SVG parsing in the prepare script uses
regexes over KanjiVG's regular attribute layout, not an XML library.

## Global constraints

- Radical numbers are 1–214. Stroke ranges and forms come only from `docs/contracts/radicals/kangxi.json`.
  Go and TS both test against it, and neither holds a second hand-written copy of the strokes or forms.
- Total strokes only (never residual). Results are ordered by strokes ascending (0 or unknown last), then
  by code point. The render cap is 300. The part threshold `minPartUse` = 10 (in `lookup.json`).
- Parts AND, radical equality, strokes equality. An empty selection gives no results.
- Both new routes are `accPublic` GETs, with no per-user data and SW `bypass`. Non-GET methods get 405
  (from the mux).
- No GPL, LGPL or unverified decomposition data is committed. `plugins/data-local/` stays gitignored.
- Secrets never appear anywhere. Pages contain no logic beyond wiring.

## Review focus

1. **Licence and credit:** the bundled pack's manifest, `LICENSE` (= KanjiVG `COPYING`), `ATTRIBUTION.md`
   and notice. The Sources page shows the pack. `docs/sources.md` and `check-sources.mjs` agree. Nothing
   copyleft is committed (`git ls-files plugins | grep -i -E 'ids|hanzi|chise'` is empty).
2. **Lookup correctness:** `lookup.json` vectors (AND parts, variants match, ordering, available parts
   and strokes, the empty selection, the cap).
3. **The `k` field:** a radical entry whose first form is a table character maps; a deleted link or a
   deleted radical entry gives no `k`. The ETag format bump to 3.
4. **Import hardening:** malformed lines name their line, self parts and duplicates are dropped or
   rejected as specified, the size caps hold, a re-import replaces the pack's rows, and uninstall
   removes rows and credits.
5. **Public routes:** 400 on a bad language, an empty body for a language without packs, ETag/304,
   gzip, and the same bytes for anonymous callers and two users.

### Deviations and rulings made while building

- Ruling: `Number` of a form listed under two radicals is the lowest number (阝 → 163, though Unihan files
  阝 itself under 170) and a radical's own character wins over a form (月 → 74) — deterministic and stated in
  the contract — cost: typing 阝 picks 邑 rather than 阜; the tile table shows both.
- Ruling: `component_packs` gains `content_hash` (and an index on `language`) beyond the spec's SQL, and
  `components.Version` hashes the live packs' ids and content hashes — `updated_at` has second resolution, so
  a re-import within a second would have kept a stale ETag (a test re-imports in the same second) — cost:
  one column.
- Ruling: a character listed by several packs of a language keeps the parts of the first pack by pack id
  (not a union of the lists); a part's `s` is the max over packs — keeps each list coherent — cost: a second
  pack cannot add parts to a character the first lists.
- Ruling: for the empty selection, `availableParts` is every part and `availableStrokes` every stroke count
  of the universe (so the pickers start enabled); written into `lookup.json` — cost: none.
- Ruling: a typed radical form that is not itself a radical's character (氵, 讠) picks the radical; a typed
  radical character (口) is a part when the language has parts, else the radical — 口 is far more useful as a
  part in ja — cost: typing 言 in ja adds a part, the tile still picks radical 149.
- The manifest has no type/format pairing check, so `components` with a wrong format is rejected by
  `components.Import` (tested there), not by `Manifest.Validate`. Parser tests use inline strings instead of a
  `testdata/` directory.
- `components.Index` returns a `Set` (the function name `Index` took the type name).
- The web module imports a byte-identical copy `apps/web/src/lib/radicals/kangxi.json` (the Dockerfile's
  web stage copies only `apps/web/`, so `docs/` is not importable at build time); `kangxi.test.ts` and the Go
  test keep both copies equal to the contract.
- The characters cache was generalised to `payloadCache` + `encodePayload` + `servePayload` and reused by
  `/api/components` (about 60 changed lines in `handlers_characters.go`).
- `fetchComponents` takes no `AbortSignal` (shared request and no error caching are kept and tested); the
  page ignores stale results by a sequence number.
- `prepare-kanjivg-components.mjs` writes `manifest.json` itself (with `--version`/`--commit`); the fetch
  script adds `LICENSE` and `ATTRIBUTION.md`.
- Two tests record decisions and passed at once: the `classify.test.ts` case (both routes `bypass`, the
  default) and the `routeAccess` line for `/search/parts` (private, the default).
- The Sources section hides during a retry (no loading state); acceptable for a credit line.
- `EXPLAIN QUERY PLAN` (logged by `TestCharactersRadical`): the radical subquery is
