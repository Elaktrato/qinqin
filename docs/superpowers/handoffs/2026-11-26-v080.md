## 2. What the review found (all fixed)

- **Stored XSS** through an images pack (an SVG comment `<!-->` slipped past both gates): the server now stores a
  canonical re-serialised form from a strict allowlist (and re-canonicalises rows already stored), the web draws
  DOM nodes instead of `{@html}`; the real packs (1,673 files) pass; CI runs the built-pack test.
- Level check sent a learner who knows HSK 1–3 back to level 1: the sample is now stratified by level.
- Kana trainer marked correct answers wrong for じ/ぢ and ず/づ.
- Tatoeba credits could not be tied to a sentence: each sentence now carries its Tatoeba id; owner and links show
  under the example (migration 054).
- Declarations: double confirm, undo deleting hand marks before the marks loaded, no retry id; offline script
  answers flushed only on `/scripts`; Chinese stage 4 hint; focus after the last hint; licence wording for the Starter
  lists; notices beside the picture maps.

## 3. Rulings (full text with costs in each plan/spec)

Headlines: declared words are known marks, not mastery (the character map ignores them); placement is self-report
(no glosses in the level lists); hints cap the suggestion at Hard; pictures come from the server pack, never the web
build or APK (BY-SA stays a separate data pack); script data and Starter lists are CC0 (documented exceptions in
`LICENSING.md`); the Starter stage is a count of spaced successes, not an FSRS threshold; picture `style` attributes
are converted, not rejected; the image route stays token-free.
