## Rulings

1. **Ruling: Figtree stays the interface font** — the mockups were judged in it, it is OFL 1.1 without a Reserved
   Font Name, one variable WOFF2 holds every weight 300–900 in 27.7 KB, and its 459 glyphs cover Latin and Latin
   Extended (the interface is English today; CJK interface text falls through to the system stack) — cost if
   wrong: swap one file and one licence text.
2. **Ruling: ship the upstream variable WOFF2 unmodified, not a Latin subset** — the file is already Latin-only
   and 27.7 KB (smaller than three static weights, 70.4 KB); leaving it unmodified means no "Modified Version"
   under the OFL, so no naming question at all — cost if wrong: ~10 KB more than a tighter subset.
3. **Ruling: hanzi/kanji slices are renamed Modified Versions** — slicing is modification under the OFL; the
   preparation script rewrites the name table's family/full/PostScript/unique names (IDs 1, 3, 4, 6, 16, 17, 21,
   22, 25) to `qinqin <Face> <script>` (e.g. `qinqin Kai SC`), keeps the copyright (ID 0) and licence (IDs 13, 14)
   entries, and the pack carries the full OFL text as `LICENSE` plus an `ATTRIBUTION.md` stating "modified
   (subset, renamed) version of <original> by <author>". One rule for every face makes Adobe's 'Source' RFN,
   LXGW's RFNs (and the "web font platform" clause of LXGW's additional permission) and Google's "Noto" trademark
   irrelevant — cost if wrong: none for users (the CSS family names are qinqin's own anyway; the Sources page
   names the original face).
4. **Ruling: a new pack type `font`, files on disk like audio, not font files inside an existing type** — no
   existing type fits: strokes and every other type are rows in SQLite that datapkg turns into synced data
   packages (`server/internal/datapkg`), which would put megabytes of binary slices into packages, backups and
   Android sync; audio is the precedent for blob files under `<data>/<type>/` with content-addressed names, and
   strokes is the precedent for a pack built reproducibly by a `scripts/prepare-*-pack.mjs` from a pinned
   upstream with its licence text checked. A font pack is **installable** through the staged upload (unlike
   audio): one face sliced into ~100–200 WOFF2 files totals 3–15 MB, well inside `maxPackUpload` (128 MiB) and
   `dict.DefaultZipLimits` (2,000 files, 512 MiB) — cost if wrong: one more `typeOrder` entry to remove.
5. **Ruling: slicing happens when the pack is prepared, never on the server** — Go has no maintained font
   subsetter; a pre-sliced pack is deterministic, served as immutable static files, and Android can use the same
   slices — cost if wrong: re-slicing needs a new pack version (normal pack update).
6. **Ruling: the interface font lives under `apps/web/src/lib/assets/fonts/` and is referenced from `app.css`**
   — Vite emits it as a hashed `_app/immutable/assets/<hash>.woff2`, so it is in the service worker's `build`
   list, precached at install and served cache-first like the rest of the shell (offline from the first
   visit), and a new font version can never be served stale. The licence text goes to `apps/web/static/` as
   `FIGTREE-OFL.TXT` like the other served licence texts (`.TXT` is kept out of the precache by
   `svelte.config.js`) — cost if wrong: none (moving a file).
7. **Ruling: no `<link rel="preload">`** — the hashed name is not known to `app.html`, and `font-display: swap`
   with a metrically close system fallback is the calm choice; the font is precached after the first visit —
   cost if wrong: one fallback-to-Figtree swap on the very first paint.
