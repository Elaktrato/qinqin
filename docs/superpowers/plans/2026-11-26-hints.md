# Hints on every flashcard — plan (issue #215)

Design: `docs/superpowers/specs/2026-11-26-hints-design.md`. Web only apart from the contract number and a backup
fixture case. Test first in every task; one commit per task. Executed subagent-driven in one pass.

1. **Pure rules and fixture** (`lib/study/hints.ts`, `hintKey.ts`, `docs/contracts/cards/hints.json`): the
   registry, `readHintSettings`, `resolveHints` (with `forced`), `visibleHints`/`nextHint`, `lowerForHints`,
   `applyHints`, `isHintKey`. Tests: `hints.test.ts`, `hints.contract.test.ts` (decodes the fixture),
   `hintKey.test.ts`; both modules added to the pure-planner import check.
2. **Card hints state and control** (`features/flashcards/face/`): `CardHints` (`cardHints.svelte.ts`),
   `HintScope`, `HintControl`, `HintShown`; the test harness gets a `hintPlan`. DOM test `HintControl.dom.test.ts`.
3. **Every card kind** gets `HintShown` and `HintControl`; Recall's "Show reading" and its private grade rule go
   (`reverse.ts` loses `readingShown`); the writing card's readings become the always-mode reading hint and its
   stroke button is renamed. Existing card dom tests updated.
4. **Session**: `HintScope` around the card, `applyHints` in `onCardDone`, the key line mentions H.
5. **Settings → Study → Hints** (`HintSettings.svelte`, dom test) and the catalogue keys (`flashcards.hint.*`,
   `settings.hints.*`, `study.session.keysHint`, `flashcards.writing.strokeHint`; two keys retired).
6. **Contracts and docs**: cards/events/settings READMEs, `CHANGELOG` `(contract 7)`, `ContractVersion` 7,
   `version.json`, `backup/remap.json` case, wiki (study sessions, settings tour), ROADMAP.
7. **E2e**: `e2e/tests/hints.spec.ts` (written; not run locally: no browser automation here, CI runs it).
8. **Verify**: vitest, svelte-check, `tsc -p e2e`, Go tests (`internal/api`, `internal/backup`); merge
   `origin/feature/v0.8.0` before each push; PR into `feature/v0.8.0`.
